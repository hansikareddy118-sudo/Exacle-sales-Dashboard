# Excel Sales Dashboard

## Project Overview
This project is an interactive Excel Sales Dashboard built using Pivot Tables, Charts, KPI Cards, and Slicers.

## Dashboard Preview
![Dashboard](dashboard.png)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- KPI Cards
- Slicers

## Insights
- Sales by Category
- Sales by Sub-Category
- Monthly Sales Trend
- Yearly Sales Trend
- Profit Analysis
